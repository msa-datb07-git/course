# env-demo

Bob's small project for the demo of session 4: `report.py` prints the revenue per region of `sales.csv`.
It needs two libraries, listed in `requirements.txt`.

```bash
python -m venv .venv
source .venv/Scripts/activate        # macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python report.py
```
